# Dock v0.3.5 candidate

- Screenshot capture throttle reduced from 650ms to 525ms while staying above Chrome's 2 captures/sec ceiling.
- Theme menu simplified to a single 3x3 theme grid; Coastal/Playful section labels removed.
- Theme Store tile centered; Coming Soon text centered inside the tile.
- Slate replaced by Smiley Pop, a new vector smiley theme.
- Skipper uses the full-resolution PNG scene and lighter chrome blur for a sharper background.

This is a descendant of the frozen 0.3.4 runtime candidate and requires its own runtime validation.
