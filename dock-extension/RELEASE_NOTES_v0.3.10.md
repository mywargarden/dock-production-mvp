# Dock 0.3.10 — Premium Theme Store Polish

- Refocuses the locked Theme Store on the product Dock actually intends to sell: premium personal themes.
- Removes district-theme, school-branding, mascot-marketplace, payment-roadmap, and other uncommitted product promises from the locked page.
- Replaces placeholder feature pills with a professional premium-theme coming-soon presentation.
- Reuses the existing Skipper Harbor artwork as a restrained brand visual rather than adding a new image-generation dependency.
- Keeps current included themes unchanged and makes clear that premium themes are additive.
- Renames the return action to `Back to Dock`.
- No sharing, memory, authentication, managed-workspace, or theme-runtime behavior is changed by this polish pass.

Candidate status: requires final visual browser validation of the locked Theme Store page before release integration.
